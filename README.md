# Swiggy Bangalore Restaurants Analysis | Tableau Dashboard

## Project Overview

This project presents an interactive **Swiggy Bangalore Restaurants Dashboard** developed using Tableau.

The dashboard analyzes restaurant distribution across Bangalore, popular locations, available cuisines, and restaurant pricing. It provides a visual overview of the restaurant landscape to help explore location-wise restaurant availability and pricing patterns.

## Dashboard Preview

![Swiggy Bangalore Restaurants Dashboard](Dashboard%201.png)

## Key Dashboard Features

The dashboard includes the following visualizations:

1. **Total Restaurants by Location:** Displays restaurant counts across different Bangalore locations.
2. **Top 3 Locations with More Restaurants:** Highlights the locations with the highest restaurant concentration.
3. **Top Mostly Available Cuisines:** Compares the availability of different cuisine types.
4. **Top 10 Hotels with High Price:** Highlights restaurants with higher listed prices.
5. **Location Distribution:** Compares the restaurant share across the top three locations.

## Key Dashboard Findings

- Kadubeesanahalli has 588 restaurants.
- Marathahalli has 585 restaurants.
- Rajarajeshwari Nagar has 494 restaurants.
- Indian cuisine is the most represented cuisine, with 440 listings.
- South Indian cuisine has 293 listings.
- North Indian cuisine has 249 listings.
- Behrouz Biryani is shown with a listed price of 10,000 in the dashboard.

## Dataset Description

The project uses the **Swiggy Bangalore.csv** dataset containing restaurant-related information for Bangalore.

The dataset supports analysis of restaurant locations, cuisine availability, and pricing.
